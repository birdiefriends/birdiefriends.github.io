BFE Host Admin Panel — Setup

Registration, roster, venues, tee policy, rounds, and payout for a BF Experiences event — generic across Wally Cup, BFCup, Turkey 2Man, and BlackFriday.

Data & reset testing tool

Shows every event currently stored on the BFE Worker (D1), with row counts, so you can see exactly what's there before testing or retesting Setup or Close Round — instead of guessing whether earlier testing left records behind. Delete wipes that event completely: its rounds, roster, and any saved round results/skins. Cannot be undone. This does NOT touch Jotform — a round's scorecard test submissions live there, not here, and aren't affected by anything on this page. It also doesn't touch player profiles or venue tee catalogs, which are meant to persist across events.

5. Tee policy

Resolved once, from the first stableford round's venue, and carried unchanged for the rest of the event. Add a stableford round above to enable this.

6. Quick HCP

Mirrors GS's Quick HCP Panel: Stored HCP is each player's last-known value from BFE's player-profiles table; New HCP is what this event will use. Load profiles, adjust New HCP per player, and Apply — the roster above updates and each profile's HCP history gets the change.

7. Payout

Uses the same proportional formula as the BFSeries payout: podium 20% of pool (weighted split), CTP 15% spread across the round's CTP holes, remainder to skins. The Overall pot is podium-only (no CTP/skins). Wally Ball is a separate winner-take-all pool, split evenly if more than one player never loses the ball.

8. Save / load on the Worker

Save persists whatever you last generated below into the Competitive Events tables (bfe_events → bfe_event_rounds → bfe_event_roster), keyed by the event name above — a real parent/child structure, not a single document (and, if checked in Tee policy, updates that venue's saved tee catalog too). Load reassembles it back from those tables.

9. Close a round

Pulls that round's scorecards straight from Jotform, runs them through the quota engine above (including any Wally Ball bonus), computes skins, and saves the result — round pot payout included. Only "Stableford quota" rounds are wired up right now; 2-man scramble scoring isn't built yet. CTP payout isn't wired yet either (shows as $0 — nothing resolves actual closest-to-pin winners from Jotform so far). Load or Generate the event above first.
