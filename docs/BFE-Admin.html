5. Tee policy

Same tee vs. by-HCP-tier is a one-time, event-wide choice. But different rounds can be at different venues, and different venues have different tee names and slopes — so the actual tee/slope values are captured separately, once per venue, below. A venue's block appears here once a stableford round above has that venue selected.

Add a stableford round above and pick its venue to see a tee policy block for it here.

6. Payout

Uses the same proportional formula as the BFSeries payout: podium 20% of pool (weighted split), CTP 15% spread across the round's CTP holes, remainder to skins. The Overall pot is podium-only (no CTP/skins). Wally Ball is a separate winner-take-all pool, split evenly if more than one player never loses the ball.

7. Save / load on the Worker

Save persists whatever you last generated below into the Competitive Events tables (bfe_events → bfe_event_rounds → bfe_event_roster), keyed by the event name above — a real parent/child structure, not a single document (and, if checked in Tee policy, updates that venue's saved tee catalog too). Load reassembles it back from those tables.

8. Close a round

Pulls that round's scorecards straight from Jotform, runs them through the quota engine above (including any Wally Ball bonus), computes skins and Closest-to-Pin, and saves the result — round pot payout included (podium, skins, and CTP). Only "Stableford quota" rounds are wired up right now; 2-man scramble scoring isn't built yet. CTP pays whoever's the most-recent qualifying claimant on each hole configured for this round's venue in section 5 — same rule the live leaderboard uses. Load or Generate the event above first.
