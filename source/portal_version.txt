v4.5.7 · 2026-09-24
Deployed: 2026-09-24 (Live Panel: (1) the CTP and BirdieBall sections now turn on/off based on the Gathering's own games config instead of always showing — a Gathering not running a game no longer clutters the panel with it. (2) New standalone BirdieBall live-alert widget, mirroring Birdie Alert's UX: pick a player, tap Kept It or Lost It (with a hole/stroke picker for a loss), and a running "who's lost the BirdieBall" board — posts to the same bfe_birdieball_answers table as the scorecard confirmation below. (3) The Post-Round Scorecard now includes a BirdieBall confirmation safety net for Gatherings running BirdieBall: if a player hasn't already answered via the live-alert widget, the scorecard asks Kept It/Lost It before it can be submitted (skipped entirely once an answer exists from either touchpoint) — covers players who forget to use the standalone alert.)
